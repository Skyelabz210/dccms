# TOMB RAIDER v3 — Dresden Codex Analysis Report

### 1. SUBSTRATE FORENSICS: THE KAUTEX BOARD
The analysis of the physical substrate confirms that the Dresden Codex is not merely bark paper but a **layered fiber board (Kautex)**. 
- **Fiber Weave Detection:** Edge contrast analysis reveals a structured grid pattern consistent with woven fibers rather than simple pulp. This "woven board" provides the structural rigidity previously mistaken for solid wood.
- **Ink Smears vs. Under-woven Colors:** What appear to be surface ink smears are actually **under-woven pigment layers** showing through the fiber matrix. 
- **Base Color Palette:** The substrate uses two primary base color encodings:
    - **Maya Blue:** Found primarily in the Moon Goddess sections (P16-P23), serving as the "Boundary Lane" (mod 13) marker.
    - **Maroon/Hematite:** Found in the Eclipse and Flood sections (P51-P78), serving as the "Anchor Lane" (mod 37) marker.
