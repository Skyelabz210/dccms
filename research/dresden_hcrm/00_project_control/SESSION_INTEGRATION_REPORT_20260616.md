## 2. Canonical project statement

### Project name

Dresden / Human-Celestial Register Map Investigation.

### Formal aim

The project investigates whether the Dresden Codex preserves a visible operator grammar for projecting a cyclic substrate through multiple resolution layers: celestial, ritual, agricultural, bodily, social, and terminal-return domains.

The natal chart is treated as a surviving human-domain mapping protocol: a birth event is projected into celestial registers, signs, houses, aspects, nodes, and body-domain correspondences. The codex is treated as the instrument surface that may preserve a related operator grammar. CRAM-style residue arithmetic is used only as an exact detector for closure, carry, heterogeneous lane transfer, shadow-prime behavior, boundary re-entry, and winding/lift behavior.

### Non-negotiable framing

The codex remains primary. The investigation does not assert that the Dresden Codex “is CRAM.” Instead, it asks whether the codex’s visible layout, numbers, deities, colors, shells, serpent paths, and section transitions mark exact cyclic operations. CRAM/CVM is a measuring instrument used to expose candidate signals.

### Evidence standard

A claim is not promoted from one event. Strong claims require recurrence, cross-section support, prediction, or a falsification check. Every strong claim must be tied to visible evidence, exact arithmetic, ledger entries, and a null or control comparison.

## 7. Exactness and falsification rules

```text
floating-point variables
floating-point constants
float(...) conversion
approximate decimal thresholds
unlabeled synthetic ephemeris values
```

Required promotion rules:

```text
G0: visible observation
G1: exact arithmetic signal
G2: local operator alignment
G3: repeated local alignment
G4: cross-section recurrence
G5: predictive confirmation
```

Strong claims require G4 or G5 status.

Downgrade rules:

```text
ordinary period-factor closure explains the event
single unreplicated alignment
uncertain visual transcription
selective grouping without visible boundary
null enumeration shows event is common
prediction fails
```
