- D000: confirm source artifacts: uploaded Dresden PDF, prior codex page 55 files, iridescent/natal app, CRAM residue packet.
- D001: freeze terminology: codex-native operator grammar, CRAM as detector only.

## G1, visual operator surface

- V010: segment codex into macro-modes: almanac lanes, dense numerical tables, vertical tables, serpent routes, large terminal panels.
- V011: identify every page boundary where lane count or visual mode changes.
- V012: mark terminal-to-opening route candidates.
- V013: build serpent body segment ledger: bends, compartments, dots/bars, red/black marks, entry/exit.

## G2, resolution descent / lift

- R020: model each macro-section as a resolution layer.
- R021: test whether domain transitions behave like residue projections from a larger state.
- R022: test whether terminal serpent/deluge pages behave like lift or return operators.
- R023: test 13-boundary behavior as visible 13 -> 1 re-entry with hidden carry.

## G3, physical lanes and color states

- L030: segment page lanes before interpreting color.
- L031: classify red/black as state annotation, not primary register until proven.
- L032: test red/black flips against carry, closure, boundary, and lift events.

## G4, deity / composite operators

- O040: assign neutral IDs to deities and attached composites.
- O041: test prime-product signatures, e.g. 5 and 3 -> 15 operator field.
- O042: compare in-range composites against out-of-range controls.
- O043: promote only repeated operator behavior across independent contexts.

## G5, HCRM natal map

- H050: convert natal chart longitudes to integer arcseconds.
- H051: compute sign, house, aspect, dignity, and body-domain ledgers.
- H052: overlay basis {2,3,5,7,11,13,17,19}.
- H053: locate 11-shadow closures and 13-boundary lifts.
- H054: compare chart register signatures against codex operator signatures.

## G6, prediction and falsification

- F060: make explicit predictions before inspection.
- F061: record failed predictions instead of deleting them.
- F062: downgrade ordinary period-factor closures.
- F063: promote only repeated, cross-section, or predictive matches.

## Terminal gate

The investigation reaches a release checkpoint only when every strong claim is tied to visible evidence, exact arithmetic, ledger entries, a null/falsification check, and a prediction test.
